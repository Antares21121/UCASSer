- 11 条带明确演示／测试标记的本地聚合信息排除在外；本地社区示例帖子和测试课程也不在本批中。

## 行为边界

`scripts/restore_public_candidates.php` 默认预演并回滚。固定数据文件有 SHA-256 校验；全部来源、同域原文 URL、日期及字段先验证，再开始导入。需要明确指定一个现有、已确认邮箱的运营账号或管理员作为审计归属；不会创建账号或授予权限。

服务器中已有同一原文链接的候选，无论待审、已拒绝或已发布，都逐行保留。新记录仅进入待审队列，不创建已发布条目、不覆盖审核意见，也不修改来源适配器、启用开关、采集时间或连接凭据。

默认跳过禁用来源。`--include-disabled` 表示明确同意把历史快照提交到这些来源的审核队列；它仍不会启用自动采集或把待授权公众号标成已连接。

## 先在服务器副本预演

将本 PR 的脚本和数据文件放入已有隔离副本，运行：

```bash
php scripts/restore_public_candidates.php --actor EXISTING_CONFIRMED_ACCOUNT --include-disabled
```

确认预演、已有候选保护和重复应用通过后，再备份线上并在暂停采集时执行同一预演及 `--apply`。指定线上已建立的运营账号，不能把本地测试用户搬过去。

```bash
php scripts/restore_public_candidates.php --actor OPERATOR --include-disabled --apply
```

预计新增数取决于服务器当前已有原文，不固定为 97。`existing_urls_preserved` 和 `added` 合计应为 97（明确包含禁用来源时）。审核通过前，公开汇集页数量不会随待审数自动增加。
