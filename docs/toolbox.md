# 校园工具箱

入口位于论坛侧栏“校园工具箱”，地址为 `/campus/tools`。现有六个入口：日历、食堂菜单、课程表、摆渡车时间表、新生导引和讲座索引。每个入口都有独立网址；日历可以切换月份。已核实的外部来源以新标签页打开，并明确标出来源与适用范围。站内不展示未经核实的活动、菜单、课程、班次或报到信息。

| 工具 | 地址 | 后续内容 |
| --- | --- | --- |
| 日历 | `/campus/tools/calendar` | 月历、[教务处历史校历栏目](https://jw.ucass.edu.cn/xnxl.htm)和[校园门户](https://info.ucass.edu.cn/)；现行电子校历需本人登录门户的“学年校历”微应用，不能把旧校历当成现行安排 |
| 食堂菜单 | `/campus/tools/dining` | 餐次、菜品、适用日期和更新来源 |
| 课程表 | `/campus/tools/timetable` | 可进入 `/campus/courses` 查看课程目录；星期、节次、地点需取得获授权的课次数据后再录入 |
| 摆渡车时间表 | `/campus/tools/shuttle` | 尚无已核实的当前时刻表；[学校迎新交通通知](https://welcome.ucass.edu.cn/info/1003/1264.htm)仅作有日期的历史来源，不能作为日常班次依据 |
| 新生导引 | `/campus/tools/new-student` | [学校迎新网](https://welcome.ucass.edu.cn/)及逐年更新的通知 |
| 讲座索引 | `/campus/tools/lecture-index` | 外部独立站点 [社科大讲座汇](https://muxin-ucass.github.io/LECTURE-INDEX/)；只提供归属清晰的跳转，不复制数据或代码 |

目前只是界面、路由和来源入口，不提供工具箱录入后台，也不会从其他模块推断个人课表。填入真实内容时，应先确定维护人、来源、更新频率和过期处理方式，再分别接入数据与管理界面。页面需显示信息的适用日期和来源，避免过期菜单或班次被误用。外部讲座站点由其维护者独立更新；本站的聚合审核信息流与该站点互不自动同步。
