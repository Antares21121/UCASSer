# 校园工具箱

入口位于论坛侧栏“校园工具箱”，地址为 `/campus/tools`。现有五个入口：日历、食堂菜单、课程表、摆渡车时间表和新生导引。每个入口都有独立网址；日历可以切换月份，其余页面显示明确的空状态。第一版不包含未经核实的活动、菜单、课程、班次或报到信息。

| 工具 | 地址 | 后续内容 |
| --- | --- | --- |
| 日历 | `/campus/tools/calendar` | 活动、学期重要日期和来源 |
| 食堂菜单 | `/campus/tools/dining` | 餐次、菜品、适用日期和更新来源 |
| 课程表 | `/campus/tools/timetable` | 课程、星期、节次、地点与学期 |
| 摆渡车时间表 | `/campus/tools/shuttle` | 线路、站点、发车时间与生效日期 |
| 新生导引 | `/campus/tools/new-student` | 报到步骤、办事入口及官方来源 |

目前只是界面和路由骨架，不提供录入后台，也不会从其他模块推断个人课表。填入真实内容时，应先确定维护人、来源、更新频率和过期处理方式，再分别接入数据与管理界面。页面需显示信息的适用日期和来源，避免过期菜单或班次被误用。
