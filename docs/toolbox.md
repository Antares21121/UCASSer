# 校园工具箱

入口位于论坛侧栏“校园工具箱”，地址为 `/campus/tools`。现有六个入口：校历、课程表、摆渡车时间表、食堂菜单、新生导引和讲座索引。本文已按当前实现更新，完整改动及验收边界见[全量盘点](change-inventory.md)。

| 工具 | 地址 | 当前实现 |
| --- | --- | --- |
| 校历 | `/campus/tools/calendar` | 展示 2026–2027 学年秋、春两学期学校发布原图，可新标签打开大图；已替代早期月历占位实现 |
| 食堂菜单 | `/campus/tools/dining` | 仍未录入，显示空状态，不虚构菜品 |
| 课程表 | `/campus/tools/timetable` | 内置标记为 2026-10-29 导出的 672 条排课快照、18 个单位、13 种类别和 15 个楼宇；按星期与节次展示，点击格子查看该时段课程，可逐门订阅 |
| 摆渡车时间表 | `/campus/tools/shuttle` | 展示学校发布的时刻表原图，可新标签打开大图；临时变动以学校最新通知为准 |
| 新生导引 | `/campus/tools/new-student` | [学校迎新网](https://welcome.ucass.edu.cn/)及逐年更新的通知 |
| 讲座索引 | `/campus/tools/lecture-index` | 外部独立站点 [社科大讲座汇](https://muxin-ucass.github.io/LECTURE-INDEX/)；只提供归属清晰的跳转，不复制数据或代码 |

## 课程订阅和筛选

课程表包含院系、课程类别、节次、楼宇和关键词筛选，提供“全部课程 / 我的课表”切换。课程弹窗显示教师、教室、学分、周次等已有字段；登录后可订阅或取消，记录存于当前用户的 `campus_course_subscriptions`，不会从别人的订阅推断个人课表。

`GET /api/campus/tools/data` 读取扩展内的 `resources/data/timetable.json`，缓存十分钟；订阅由 `/api/campus/timetable/subscriptions` 读写。校历与摆渡车图片经 `/api/campus/assets/{file}` 的固定白名单提供。

## 更新与验收边界

当前是随代码发布的排课快照及图片，不是实时登录校园门户同步，也没有独立工具箱数据录入后台。学校发布新安排后应核对来源、适用日期和变更范围，再更新快照或图片。外部讲座索引独立维护，本站只提供跳转，不复制其内容或自动同步至信息汇集。

已有匿名公网读取与展示检查覆盖排课数据、格子弹窗、校历/摆渡车图片和部分窄屏布局；真实账号订阅、取消、刷新后的持久化仍须另做线上验收。源码和开发浏览器测试存在，不应表述成所有线上操作均已通过。
