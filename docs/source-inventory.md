## 目前已接入的公开网页

学校首页通知、13 个学院的通知栏目，以及教务、招生、学工、团委、科研、规划评估、网络、研究生教育、保卫、迎新、国际教育、终身教育、国际交流、工会、继续教育、财务、人事、就业和招投标采购等部门或中心的公开栏目。税务硕士教育中心的公开通知也已列入。部分机构有多个栏目，运行 `scripts/aggregation_sources.py` 后可在来源管理页逐项暂停。网页仅抓标题、时间、摘要和原链接，新候选需管理员审核。

## 官网可以核实身份，但尚需人工订阅的公众号

学校账号、校团委、文学院、社会与民族学院、哲学院、保卫处，以及历史学院、经济学院、商学院、法学院、法硕中心、政府管理学院、政管 MPA、新闻传播学院、应用经济学院、全球与区域国别学院前身“国际政治经济学院”、马克思主义学院下属“思创社科”、图书馆和就业相关账号。另有法学院相关的 `UCASS LAW`、互联网法学和科研处账号。每个账号的官网证据 URL 与名称一起保存在源码中，便于管理员逐条核对。

该清单只能证明官网曾使用这些名称；改名、停更和是否仍由相应机构运营，需要在订阅前再次核对。微信读书采集模式通常只能取得最新一篇，不能保证找回两次运行之间发布的全部文章。公众号文章依然进入审核队列。

## 仍需核对

- [网络中心网站群目录](https://nc.ucass.edu.cn/xxfw/wzjs/wzq1.htm)收录更多站点，但存在旧机构名称，需逐个比对现行机构和可访问的通知栏目，不能直接整表启用。
- 金融硕士、税务硕士、法学院互联网法治研究中心、学院团学组织及各研究中心有独立网页或公众号线索；只有能确认当前名称、网址与栏目结构的才应接入。税务硕士通知栏目已经核实并接入，其余候选继续核对。
- 公众号没有可靠的公开全校总目录；学院未在官网披露的公众号不能凭搜索结果判定为官方。可由学院提供原文链接或二维码，管理员核实后再在独立订阅服务中添加。
- 校园门户、微信群和其他登录后内容不属于公开网页采集范围；需使用各自获授权的导出或成员投稿流程。

## 授权失效时

`scripts/aggregation_weread.py` 会把 `ready`、`authorization_required` 或 `unavailable` 状态写入论坛设置表，不写入令牌、密码和二维码。管理员在来源管理页看到重新授权弹窗。订阅服务若部署在自己的电脑，点击弹窗里的本机地址并在独立工具里扫码。若部署在云服务器，先用受保护的通道把服务器 `127.0.0.1:8001` 转发到电脑的同一端口，再点击；不要在安全组或反向代理中公开该管理端口。扫码后手动运行一次 `scripts/aggregation_weread.py --env-file .env.test` 验证状态和入队结果。
