# 隐私与个人数据

正常账号公开发布的内容显示账号昵称；不要提交不应公开的姓名、电话、学号、身份证号、聊天记录或他人材料。校园评价没有匿名入口，也不作匿名保护承诺。联系方式和资料授权由发布者核实。

人工校园验证只接受自愿提交的最少文字说明，明确同意后才保存。材料仅管理员待审队列可见；普通用户自己的历史不含原始材料。批准、拒绝或撤销时删除原始说明，保留状态、时间和必要处理理由。处理理由禁止复制个人材料。没有身份文件上传接口。

个人中心、收藏和反馈按本人隔离。举报材料仅举报者与获授权处理人员可见，被举报人只能查看处理结果；处理人员不得处理自己提交或涉及自己的举报。申诉由不同于原处理人的人员复核。公开治理只包含管理员主动发布的公开内容，不公开举报人身份；举报数量少于 5 条不展示汇总。

账号设置复用官方 GDPR 导出、清除申请与管理员处理流程。导出下载还要求有效登录会话，只有申请者或管理员可下载；分享下载链接不会直接赋予访问权限。校园导出包含本人的验证记录、授权、收藏、反馈、评价和本人举报，排除他人的举报和审核人标识。

个人清除会删除验证、授权、收藏、有用反馈及本人纠错，解除记录、审计、治理与处理事件的账号关联，移除本人举报原始材料与历史正文副本。公共贡献按官方匿名化策略保留，当前公开正文和公开字段也可能包含作者主动写入的信息：删除前应检查并申请清除需要移除的个人内容。匿名化账号不等于提供匿名发表功能。

限制：自由文本中的第三方个人信息无法通过解除账号关联自动识别。管理员需按申请范围审查当前内容、历史元数据、处理理由、日志和附件；不得宣称自动匿名化能够清除任意嵌入的身份线索。默认允许匿名化，不开放未经确认的永久删除路径。

数据库和备份包含用户数据及后台 SMTP 设置，必须作为秘密保管。日志不得转发原始确认/重置令牌、认证材料或密码。限流只存摘要桶，不保存原始 IP、账号识别字符串或密码。开发测试 SMTP 捕获在进程内，不向外部投递；本地邮箱读者只监听回环地址。

保留策略：已审核验证材料立即清除；限流过期桶定期在写入时清理；开发邮箱停止后清除。讨论与治理历史默认长期保留以积累公共知识。正式运行前维护者必须确定举报/审计/日志/备份的保留期限、受理联系人、法律适用和删除后备份到期策略；未设置自动业务归档任务。备份恢复后应重放尚未过期的删除申请，防止个人数据重新出现。
