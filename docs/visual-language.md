# 访客端视觉语言

UCASSer 是同学共建的独立论坛，不使用中国社会科学院大学的校徽、校名题字或校园照片作为本站标识。首页明确标注“非学校官方平台”。

## 版式与配色

视觉关键词为「校园资料馆 × 青年编辑部」：暖纸白 `#F7F4EE` 作页面底色，正文深墨蓝 `#1C3042`，品牌色为深校园红 `#A71937` 与强调红 `#C22A49`，浅雾蓝 `#DFEAF2` 仅作浅色块与插画底色。首页标题使用深红文字与细红线，不使用整块高饱和红底白字。正文与按钮满足 WCAG AA 对比度；品牌主题跟随系统明暗模式（顶栏不设皮肤切换按钮）。

## 图片来源与许可

本次改版的全部位图均为本站原创矢量插画（SVG），存放于 `extensions/campus/assets/`，由本项目作者绘制并以 CC0 1.0 许可发布，可自由使用、修改与分发，无需署名：

- `hero.svg` / `hero-tall.svg`：首页主视觉（书桌、打开的书、笔记、咖啡杯与抽象建筑轮廓），16:10 与竖版裁切。
- `courses.svg`：课程目录卡（课程笔记、书签、目录卡片）。
- `resources.svg`：资料目录卡（文件夹与书页）。
- `life.svg`：校园生活卡（帆布袋、绿植、水杯）。
- `secondhand.svg`：二手交易卡（书本、台灯等可转让实物）。
- `travel.svg`：出行信息卡（车票、背包、路线地图线）。
- `questions.svg`：校园问答卡（两本打开的书与便签）。
- `careers.svg`：实习就业竞赛卡（公文包与文件）。

插画刻意不含文字、校徽、大学名称或可识别的真实建筑，不与内容语义混淆。每张卡图固定 4:3 容器，懒加载，装饰图空 alt，首屏主图优先加载；低网速与关图时布局与文字完整。

若后续引入真实摄影素材，必须是有明确商业使用许可的图片（如自有摄影、CC0/CC BY 或已购授权图库），并在本文件记录来源、作者与许可证；禁止使用学校官网图片或无法辨认出处的图库拼贴。

首页线稿源自此前版本的原创图形（书页与建筑立面），不描绘某栋真实建筑。底色与正文层级遵循同一规则：维护时先检查文字与按钮对比度、320px 手机不横向滚动、链接可用、动态内容不被装饰遮挡；插画仅用于视觉装饰，不承载必要信息。
