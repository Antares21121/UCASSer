# 访客端视觉语言

UCASSer 是同学共建的独立论坛，不使用中国社会科学院大学的校徽、校名题字或校园照片作为本站标识。首页明确标注“非学校官方平台”。

首页线稿是本站原创图形：书页对应资料与知识，建筑立面和贯穿的中线借鉴[良乡校区建设规划](https://jjc.ucass.edu.cn/zhongguoshekeyuandaxue-yanjiushengyuan-liangxiangxiaoqujibenjiansheguihua.pdf)中关于校园中轴线、图书馆和教学楼的空间描述，并不描绘某栋真实建筑。[学校概况](https://ghypgc.ucass.edu.cn/__local/0/A4/E4/070890FC1F6315CF5E3A0F47128_3C5FE0AA_2E9EAB.pdf)提到良乡与望京两个校区，首页以此确认服务对象；没有复制学校官方页面的版式。

底色使用偏暖的纸张色，正文使用深墨色。少量赭红色仅作书签和分隔标记；可操作链接与按钮保留论坛原有蓝色，使它们容易辨认。深色模式保持同一层级。维护时先检查文字与按钮对比度、320px 手机不横向滚动、链接可用、动态内容不被装饰遮挡；线稿仅用于视觉装饰，不承载必要信息。
