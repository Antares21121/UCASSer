# 功能与使用入口

业务扩展位于 `extensions/campus`，使用原仓库锁定的 Flarum 2.x。数据库中的真实内容驱动所有页面；开发示例均标注「【示例】」。分阶段状态见 [roadmap.md](roadmap.md)，实际测试见 [testing.md](testing.md)。

| 模块 | 入口 | 实际行为 |
|---|---|---|
| 首页 | `/campus` | 十个分区、最新发布、近期热门、问答、活动与截止日期；权限、错误、空状态与移动布局 |
| 身份 | `/campus/identity`、原生 `/settings` | 原生注册、确认、重置、昵称、偏好；自愿人工验证、审核后清除材料、撤销与重新申请 |
| 校园信息 | `/campus/records?type=information` | 分类、来源、期限、状态、精选、预览、修订、评论与私有纠错 |
| 资料库 | `/campus/records?type=resource` | 链接索引、版权说明、课程/主题/年级、版本关联、核验状态、失效反馈与收藏 |
| 问答 | `/campus/records?type=question` | 背景、回答、提问者采纳/取消、状态、相关问题；维护者整理有授权的答案为资料 |
| 课程评价 | `/campus/courses` | 课程维护、学期、三个明确的 1–5 评分、有效样本与均值、经验、编辑、撤回/恢复、有用反馈 |
| 个人中心 | `/campus/me` | 本人发布、收藏、普通讨论收藏、回答、原生关注与通知偏好入口 |
| 搜索 | `/campus/search` | 普通讨论和四种内容、摘要、分类/分区/课程/学期/状态/日期、排序、每页 20 条；权限过滤 |
| 举报 | 帖子操作「举报并跟踪处理」、`/campus/cases` | 私有举报、补充、分区队列、处理理由、状态、隐藏/恢复、管理员严重处置、申诉及独立复核 |
| 治理 | `/campus/governance`、`/campus/rules` | 公开规则/职责/决定/维护/招募的不可覆盖版本、生效时间、真实汇总、分区授权数量 |
| 管理 | `/admin#/extension/ucasser-campus` | 分区、分类、人工验证、分区授权与撤销、验证撤销和私有审计；课程/治理维护在相应论坛页面 |

课程评价使用正常账号，**匿名功能关闭**，接口也拒绝匿名请求。没有教师排名、推荐算法或虚构样本。课程均值是当前访问者可见且未撤回评价的 SQL 聚合，空样本返回空值；不用于事实性判断。

资料只索引合法的 HTTP(S) 来源，不托管课程课件附件。头像上传复用 Flarum；未新增附件系统。关注、回复邮件、提及、通知已读、原生点赞、置顶、锁定、账号与 GDPR 复用已安装官方扩展。校园通知不缓存敏感正文，访问范围变化后相应通知会被过滤。

修订正文仅作者和获授权维护人员可查；对外显示版本、时间与修改理由。因此修改理由不得包含个人材料。原生编辑结构化讨论也保存版本。举报不会自动处罚；举报者身份不向被举报人公开。当事人仍须有讨论访问权限才能打开正文。

界面中的 UTC 时间明确标注。为维护访问边界，问答转资料要求两分区的可见范围一致。被第三方隐藏的内容不能被普通作者借编辑恢复；评价作者可以恢复本人主动撤回的评价。

正式名称、分区公开范围、志愿人员和 SMTP 由维护者配置。生产 HTTPS、外发邮件、异地备份、告警与正式 2.x 升级属于上线前检查；此仓库不声称已经部署生产环境。
