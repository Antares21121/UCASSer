# 邮箱注册与登录

账号使用 Flarum 2.x 原生流程。访客填写用户名、邮箱和密码注册；确认邮件发送到所填邮箱。登录表单接受邮箱或用户名，加上密码。邮件中的链接先打开确认页面，用户点击「确认邮箱」后才完成激活。未确认账号虽然可以登录和管理自己的账号，但校园成员内容、投稿、身份申请等入口仍按访客处理。

## 开放注册前

1. 确认正式站点已使用 HTTPS，且后台「邮件」中的发件地址、SMTP 主机、端口、加密方式和认证信息由运维配置。不要把 SMTP 密码写进 `.env`、代码或工单。
2. 从后台发送测试邮件到维护者控制的邮箱，确认实际送达；再用一个新邮箱完成注册、收信、确认和退出后的邮箱密码登录。测试邮件发送成功不能代替真实收件确认。
3. 在后台「基础设置」开放注册，并核对访客、成员和校内验证成员的权限。若邮件尚不能送达，先保持注册关闭；未确认者无法使用校园成员功能。
4. 检查重发确认邮件与「忘记密码」是否能收到。生产邮件服务故障时，先修复投递，不要通过手工修改数据库批量确认账号。

## 本地验收

开发环境运行 `python scripts/dev_mail.py --backend docker`（Windows 便携环境用 `--backend native`），在 `http://127.0.0.1:8026` 查看本地捕获的确认信。这个工具只为测试临时设置 SMTP，停止后恢复旧设置，不会外发。运行 `python tests/campus_smoke.py --backend docker --phase 2` 可验证待确认限制、确认表单提交、邮箱密码登录和密码重置；需要先按 [测试说明](testing.md) 建立独立开发实例。

本地捕获成功只证明应用能生成邮件。正式站点还需要在真实收件箱里完成上述流程，确认发件域名、垃圾邮件处理和送达情况。
