## 十二、最容易被误判为“丢了”或“已经做完”的地方

1. **聊天输入栏没有丢**：私信收缩规则及图片按钮在当前线上资源中。真实私信发送和显示还需完整操作验收。
2. **公开回复多一个 @ 是当前实现**：不擅自把它与私信要求混同；结构化发布还保留业务字段。
3. **课表不是空入口**：672 条排课、格子弹窗、订阅代码都在，线上展示已实测；但门户实时同步、真实订阅持久化不是同一个结论。
4. **校历和摆渡车不是都未接入**：当前原图在线可加载。菜单仍为空，讲座只外链，不能一概归为“工具箱完备”或“工具箱没做”。
5. **等级显示不代表经验系统已经上线**：目前只是 Lv.1/0 XP 基础。
6. **删除资料不是物理删除**：归档后应从公开目录隐藏，重加同链接应允许。这两件事需要一起验收。
7. **板块数量不同不等于丢帖**：旧板块退休、标签隐藏、内部归档和 301 都是有意改动，内容迁移仍需核验。
8. **公开信息流为 0 不等于采集数据都没了**：当前恢复的是待审记录，没有自动发布。
9. **后台权限不是“管理员才能进”**：现有实现需要独立运营授权，纯论坛管理员并不自动获得运营入口。
10. **一键采集排队、runner 在线、定时器启用都不等于采集成功**：最近一次定时失败以及学校连接超时是实际故障。
