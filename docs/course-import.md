# 获授权开课表导入与课程索引

此入口只处理管理员取得使用和公开许可的校园门户导出文件。它不要求管理员提供密码，也不读取浏览器登录状态。第一版导入的是**课程目录**，不是个人课表或每个班次的上课时间表。

## 文件格式与公开范围

把导出文件保存为 UTF-8 CSV，放进工作区的 `.runtime/` 目录。必须包含以下四列；可以有其他列，但程序会忽略它们，不写进数据库或页面。

| 公开列 | 可识别的标题示例 |
| --- | --- |
| 课程代码 | `课程代码`、`课程编号`、`课程号`、`course_code` |
| 课程名称 | `课程名称`、`课程名`、`course_name` |
| 开课学院 | `开课学院`、`开课单位`、`教学单位`、`学院` |
| 学期 | `开课学期`、`学年学期`、`学期` |

示例（真实内容须来自获授权导出，不要拿示例当学校课程表）：

```csv
课程代码,课程名称,开课学院,开课学期
DEMO001,【示例】课程,【示例】学院,2026秋
```

教师、教室、学生姓名、学号、联系方式、个人选课信息等列不会进入公开目录。最多读取 20 MB、20,000 行；同一课程代码、学院和学期的多班次合并为一个课程条目。如果这三个字段相同而课程名不同，整份文件在写入前被拒绝。

## 在测试站导入

先备份数据库并完成校园扩展迁移。以下路径适用于当前 `/opt/ucasser-test` 测试站；Windows 本地站可去掉 `sudo` 和 `--env-file .env.test`，使用 `.env`。

```sh
cd /opt/ucasser-test
sudo python3 scripts/forum.py --env-file .env.test backup
sudo python3 scripts/campus.py --env-file .env.test migrate
sudo install -d -m 700 .runtime
# 将获授权 CSV 以安全文件传输方式保存为 .runtime/course-import.csv
sudo python3 scripts/course_import.py --env-file .env.test .runtime/course-import.csv
sudo python3 scripts/course_import.py --env-file .env.test --apply .runtime/course-import.csv
```

第一条导入命令只预览总数、新增数和名称冲突数；确认公开范围和来源许可后才运行 `--apply`。不要把 CSV 上传到 GitHub、聊天记录或网站附件。导入成功后可按机构的数据保留要求处理本地原文件；工作区 `.runtime/` 已被 Git 忽略。

## 页面与后续修订

- `/campus/courses` 显示课程名、代码、学院、学期；可按名称、代码或学院搜索。点击课程可查看和发布该课程 ID 对应的评价。
- 若资料目录扩展已启用并迁移，导入器在 `/resources` 的对应学院下创建“待分类课程”索引，并在课程卡片提供入口。维护者核定必修或选修性质后，可再整理分类和资料链接。没有资料链接时索引为空，不会制造或复制课程材料。
- 用同一文件再次导入不会增加重复课程。若相同代码、学院、学期的课程名称变化，会记作待复核，不覆盖既有课程、评价或资料目录。导入批次只保存文件 SHA-256、数量和时间，不保存原 CSV。
- 现有手工课程和评价不会按名称自动合并；同名可能是不同课程。确需归并时，管理员应核对课程代码、学院与学期，并单独规划数据迁移。

如果授权导出只提供 Excel 或 PDF，先在本地转成 UTF-8 CSV 并核对这四列。目前没有校园门户自动登录或定时获取课程表的能力。每天定时刷新需要学校允许的稳定导出或 API；不能把本导入命令直接当作门户抓取任务。
