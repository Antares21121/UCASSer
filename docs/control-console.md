# 站点控制台

站点运营者登录有管理权限的账号后，在论坛侧边栏打开 `/campus/control`。这是集中操作界面，不是账号资料页；未登录或没有管理权限的用户无法读取对应接口。

控制台汇总真实数据库中的待审核汇集信息、身份申请、未结举报申诉，以及用户、讨论、校园内容和来源数量。待办可直达对应的审核标签或筛选后的未结案件页面。来源列表显示最近检查和报错；已接入本站采集的官网栏目及就业中心来源可在此暂停或恢复，操作立即写入来源记录和审计日志，下一次定时抓取会遵守该状态。新登记但尚无适配器的网站，以及由外部服务导入的公众号，不提供假的“一键开启”按钮。

控制台不检查 Docker、定时任务、SMTP 或外部公众号服务的存活状态；页面时间是汇总生成时间，不是最近抓取时间。网页抓取仍由部署环境按 [信息汇集交接](aggregation-handoff.md) 配置定时命令；公众号授权与订阅仍在独立服务中完成。来源登记、投稿与审核的原有流程保持不变。

页面沿用论坛现有蓝色交互色、字体与组件。信息来源区以已接入的[中国社会科学院大学教务处公开通知列表](https://jw.ucass.edu.cn/tzgg.htm)为实际来源示例；控制台本身展示的是站点运营数据，不展示通知正文。论坛为独立社区，因此控制台未复制学校校徽、官方照片或使用易被误认为学校官方后台的标志。
