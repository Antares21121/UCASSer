# 已安装公众号服务的内部连接

适用于当前已安装的固定镜像 `ghcr.io/rachelos/we-mp-rss@sha256:af771f21b3f7958a5dea16911fba050a6d7b92eac2fb2499c467c1b11f07ef34`。升级镜像需重新核对模型和 API，工具不会盲目初始化其它版本。

论坛容器里的 `127.0.0.1` 是该容器自身。服务端口仅绑定宿主机回环地址时，另一个容器也不能靠宿主机网关访问这个回环监听。这里把采集器加入论坛已有的 Compose 默认网络，使用容器 DNS 名称互通，保留原有 `127.0.0.1:8001` 绑定。

## 先预览，再连接

```bash
sudo python3 scripts/connect_collector.py --root /opt/ucasser-test --env-file .env.test
sudo python3 scripts/connect_collector.py --root /opt/ucasser-test --env-file .env.test --apply
```

只支持已经运行的论坛和采集器。新初始化要求采集器没有文章、没有订阅，且仅有一个启用的管理员。已有非本工具管理的凭据、已有订阅或不同网络／镜像等情况会停止；不会重置旧账号密码。

默认预览会在独立 SQLite 事务中校验新用户字段及密码哈希兼容性，然后显式回滚；不使用上游默认自动提交的 ORM 会话，不留下测试用户，不写连接文件、不改变网络。Linux 服务器的实际固定版本必须先通过该预览。

应用前对独立采集器 SQLite 做一致性备份，保存在 `.runtime/collector-connect-*/`，该目录仅 root 可读。新建一个 `role=user` 的内部连接账号，保留原管理员及其密码。随机凭据通过标准输入送入服务，不进入命令参数和日志；连接文件为 root:www-data、0640，备份凭据为 0600，不进入 Git。工具重试复用同一凭据，不重复创建账号；已有连接身份冲突时停止。

`.runtime/we-mp-rss.env` 的 `BASE_URL` 只供论坛容器使用，优先于旧的 `MP_RSS_URL`；定时采集脚本仍从宿主机回环端口访问同一服务。工具不会修改论坛环境文件、数据库、管理员、运营账号或审核队列，不会开放新的公网端口。

## 授权与定时运行是后续验收

结果 `authorization_required` 表示网络和服务登录已接通，仍需维护者亲自扫码。运营后台通过受保护的图片接口中转二维码；无需开放采集器管理端口。点击采集时若未授权，现有后台会提示并打开扫码窗口。

用户此前选择暂缓证书。公网后台输入账号和扫码应在 HTTPS 配好后进行；内部连接准备可以先完成。不要把网络连接成功、定时器已启用或历史快照入队当作微信已授权或定时采集已成功。当前服务器连接学校官网仍超时，已测得本机可正常采集的公开栏目可以用本地快照补充。
